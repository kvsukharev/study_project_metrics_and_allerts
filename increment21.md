# Increment 21 — Code generator for Reset() methods

## Что сделано

### Структура

```
cmd/reset/
└── main.go                      — генератор Reset()-методов

internal/audit/
├── audit.go                     — структура Event помечена // generate:reset
└── reset.gen.go                 — сгенерированный Reset() для Event
```

### Генератор (`cmd/reset/main.go`)

Сканирует все пакеты, начиная с корневой директории:
- Пропускает скрытые директории, `vendor/`, `testdata/`
- Игнорирует файлы `*_test.go` и `reset.gen.go`
- Парсит AST с комментариями (`parser.ParseComments`)

Для каждого пакета находит структуры с аннотацией `// generate:reset`:
- Проверяет `GenDecl.Doc` (комментарий перед `type`) и `TypeSpec.Doc` (внутри `type (...)` блока)

Для каждой найденной структуры генерирует `Reset()` метод:
| Тип поля | Генерируемый код |
|---|---|
| `int`, `uint`, `float`, `complex`, `byte`, `rune` | `s.Field = 0` |
| `bool` | `s.Field = false` |
| `string` | `s.Field = ""` |
| slice (`[]T`) | `s.Field = s.Field[:0]` |
| map | `clear(s.Field)` |
| указатель на примитив | `if s.Field != nil { *s.Field = <zero> }` |
| указатель на структуру/неизвестный тип | `if s.Field != nil { if _r, _ok := any(s.Field).(interface{ Reset() }); _ok { _r.Reset() } }` |
| именованный не-примитивный тип | `if _r, _ok := any(&s.Field).(interface{ Reset() }); _ok { _r.Reset() }` |
| интерфейс, канал, функция | `s.Field = nil` |

Результат форматируется через `format.Source()` и записывается в `reset.gen.go` пакета.

### Запуск

```bash
go run ./cmd/reset/...
```

### Пример сгенерированного кода

Для `audit.Event` (помечена `// generate:reset`):

```go
// Code generated by reset; DO NOT EDIT.

package audit

// Reset resets all fields of Event to their zero values.
func (e *Event) Reset() {
    if e == nil {
        return
    }
    e.TS = 0
    e.Metrics = e.Metrics[:0]
    e.IPAddress = ""
}
```
